# Security Policy

## Supported Versions

Security fixes are applied to the default branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Instead, report privately by contacting the maintainer directly:

- GitHub: open a private security advisory in this repository after publication, or
- Email: provide a dedicated security contact before making the repository public.

If no private channel is available yet, open a minimal public issue without exploit details and request a secure contact path.

## What to Include

Please include:

- A clear description of the issue.
- Impact and affected endpoints/components.
- Reproduction steps or proof of concept.
- Suggested mitigation, if available.

You should receive an acknowledgement as soon as practical, with follow-up on triage and remediation timing.
